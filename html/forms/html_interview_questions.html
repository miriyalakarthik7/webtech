WEB INTERVIEW QUESTIONS



  1. What is HTML?

    2. HTML stands for HyperText Markup Language. It is the standard markup language used to create the structure of web pages.

  2. What is the difference between a tag, an element, and an attribute?

    • Tag: A keyword enclosed in angle brackets, such as 'paragraph'.
    • Element: The complete HTML structure, including the opening tag, content, and closing tag.
    • Attribute: Additional information provided inside an opening tag.
  3. What is a web page and a website?

    • Web page: A single document displayed in a web browser.
    • Website: A collection of related web pages available under a common domain.
  4. What is the difference between a web browser and a web server?

    • A web browser is software used to access and display websites.
    • A web server is software or a computer that receives requests and delivers web content to clients.
  5. What is the Internet?

    6. The Internet is a global network of interconnected computers and devices that communicate using standard protocols. It allows us to access websites, send emails, make video calls, and share information.

  6. What is the difference between the Internet and the World Wide Web?

    • Internet: The global network connecting computers and devices.
    • World Wide Web (WWW): A system of interconnected web pages and resources accessed through the Internet.
  7. What is a URL?

    8. URL stands for Uniform Resource Locator. It is the address used to locate a resource on the Internet.

  8. What is DNS?

    9. DNS stands for Domain Name System. It translates domain names into IP addresses so that computers can locate the appropriate servers.

    Example: When you enter www.google.com, DNS helps your device find the corresponding server address.

    • Block elements normally start on a new line and occupy the available width of their containing block.
    • Inline elements normally flow within a line and occupy only the space their content requires.
  12. What is the difference between "div" and "span" ?

    • "div" is a generic container commonly used to group larger sections of content.
    • "span" is a generic inline container commonly used to style a small portion of text.
  13. What are semantic HTML elements?

    • Header - Introductory content
    • Nav - Navigation links
    • Main - main page content
    • Article - self contained content
    • Footer - footer content

  16. What is an HTML form?

      17. An HTML form collects information from users and submits it for processing.

  17. What are the different types of lists in HTML?

    • Ordered list: Displays items in a sequence using numbers or other markers.
    • Unordered list: Displays items using bullets.
    • Description list: Displays terms and their descriptions.

  18. What is the difference between < head > and < body >?

    • The < head > contains document metadata and references to resources
    • the < body > contains the page content presented to users.
  19. What is the purpose of the < !DOCTYPE html > declaration?

    • < !DOCTYPE html > tells the browser to interpret the document using modern HTML standards mode.
    • Note: It is a declaration, not an HTML element or a closing tag.
  20. What is the difference between < b > and < strong > ?

    • < b > draws attention to text without necessarily indicating special importance.
    • < strong > indicates that the content has strong importance, seriousness, or urgency.
    • Both are commonly displayed in bold by default, but < strong > has semantic meaning.
  21. What is the difference between < i > and < em > ?

    • < i > represents text in an alternate voice, mood, or category, such as a technical term.
    • < em > indicates stress emphasis.
    • Both are commonly displayed in italics by default, but their meanings differ.
  22. What is the difference between < br > and < hr > ?

    • < br > inserts a line break.
    • < hr > represents a thematic break between sections of content, commonly displayed as a horizontal line.

  24. What is the difference between absolute and relative URLs in HTML?

    • A relative URL identifies a resource in relation to the current document's location or its base URL.
    • An absolute URL provides a complete URL, including the scheme and host.
    • Note: Relative URLs are useful when linking to resources within the same website.
  25. What is the purpose of the alt attribute in an image?

    26. The alt attribute provides alternative text for an image. Screen readers can use it to communicate the image’s meaning, and browsers may display it if the image cannot load.

    Important: Meaningful images should have appropriate alternative text. Decorative images should generally use alt="".

  26. What is the difference between href and src?

    • href specifies a hyperlink or the location of a linked resource.
    • src specifies the source of an embedded resource.
    • Note: Links commonly use href, while images and external scripts use src.
  27. What is the difference between < a > and < link > ?

    • < a > creates a hyperlink that users can follow.
    • < link > connects the current document to an external resource, commonly a stylesheet.
    • The < a > element is normally placed in the < body > , while < link > is commonly placed in the < head >.
  28. What are HTML entities?

    29. HTML entities represent reserved characters or special symbols that may need to be displayed as text.

  29. What is the difference between readonly and disabled?

    • readonly prevents the user from editing a supported form control, but its value is generally submitted with the form.
    • disabled prevents normal interaction with the control, and its value is not submitted with the form.
    • Note: Read-only fields can generally be submitted; disabled fields are excluded from normal form submission.
  30. What is the difference between placeholder and value?

    • placeholder displays a hint when the input is empty.
    • value specifies the input’s initial value.
    • The first field displays a hint. The second field starts with the value
    • Note: A placeholder should not replace a proper < label >.
  31. What is the purpose of the required attribute?

    • The required attribute makes a form control mandatory before a normal form submission can proceed.
    • If the user leaves the field empty, the browser normally prevents submission and displays a validation message.
    • Note: Server-side validation is still necessary because client-side validation can be bypassed.
  32. What are the different types of input fields in HTML?

    • date - date selection
    • radio - select one option from the group
    • checkbox - Select independent options
    • file - Choose files
    • tel - Telephone number
    • url - URL input
    • submit - Submit a form

  33. What is the difference between radio buttons and checkboxes?

    • Radio buttons: Allow the user to select one option from a group when the controls share the same name.
    • Checkboxes: Allow the user to select multiple independent options.
    • Note: Here, the radio buttons share the same name, while the checkboxes can be selected independently.
  34. What is < select > in HTML?

    35. The < select > tag is used to create a dropdown list that allows users to select an option from a predefined list of options.

  35. What is < datalist > in HTML?

    36. The < datalist > tag provides a list of predefined suggestions for an input field, allowing users to select a suggestion or enter their own value.

  36. What is the purpose of the name attribute in a form?

    • The name attribute identifies a form control when its data is submitted to the server.
    • Note: A form control generally needs a name to contribute its value to normal form submission. An id is primarily used to identify the element in the document and associate it with a label.
  37. What is the difference between < table >, < tr >, < th >, and < td >?

    • < table > - Defines the table
    • < tr > - Defines a table row
    • < th > - Defines a header cell
    • < td > - Defines a data cell
  38. What are colspan and rowspan?

    • colspan allows a table cell to span multiple columns.
    • rowspan allows a table cell to span multiple rows.
  39. How do you insert an image in HTML?

    • Use the < img > element with the src and alt attributes.
    • Example: <img src="photo.jpg" alt="My photograph" width="300" >
    • src specifies the image location.
    • alt provides alternative text.
    • width specifies the displayed width.
  40. How do you create a hyperlink that opens in a new tab?

    • Use the < a > element with target="_blank".
    • < href="https://www.google.com" target="_blank" rel="noopener" > Open Google </a >
    • href specifies the destination.
    • target="_blank" requests that the destination open in a new browsing context, usually a new tab.
    • rel="noopener" prevents the opened page from accessing the original page through window.opener.
  41. What is the difference between action and method in an HTML form?

    • action specifies the URL to which the form data is submitted.
    • method specifies the HTTP method used for submission, such as GET or POST.
  42. What is the difference between async and defer in HTML script tags?

    • Both attributes allow external JavaScript files to be downloaded without blocking HTML parsing during the download.
    • async: Executes the script as soon as it is ready. Execution order is not guaranteed.
    • defer: Executes the script after HTML parsing finishes, preserving the order of deferred scripts.
    • Note: Use async for independent scripts that do not depend on execution order.
    • Use defer when scripts depend on the parsed HTML or need to execute in document order.
  43. What is the purpose of the < meta > tag?

    • viewport : helps the page display appropriately on mobile devices.
    • description : provides a summary of the page.
    • title : sets the document title displayed in the browser tab.
  44. What is the difference between < select > and < datalist > in HTML?

    • < select > : Creates a dropdown list that allows users to select an option from predefined choices.
    • < datalist > : Provides suggestions for an input field, allowing users to select a suggestion or type their own value.
  45. What is Local Storage in HTML?

    • Local Storage is a web browser storage mechanism that allows websites to store data that remains available even after the browser is closed and reopened, until the data is cleared.
    • Real-life example: A website remembers your preferred dark mode even after you close and reopen the browser.
  46. What is Session Storage in HTML?

    • Session Storage is a web browser storage mechanism that stores data for a particular page session. The data is normally cleared when that tab or window’s page session ends.
    • Real-life example: A website temporarily stores information while you complete a form in a browser tab.
  47. What is a Cookie in HTML?

    • A cookie is a small piece of data stored by a website in the user’s browser. It is commonly used to remember user preferences, maintain login sessions, and track user activity.
    • Real-life example: When you log in to a website, a session cookie can help the website remember your login session as you navigate between pages.

  49. What is the difference between name and id attributes in HTML?

    • id: Uniquely identifies an HTML element within a document.
    • name: Identifies form data when it is submitted to the server.
    • An input generally needs a name attribute to submit its value through a standard HTML form, whereas id is commonly used to associate a label with the input.
  50. What is the difference between < button > and < input type="submit" > in HTML?

    • < button > : Creates a button that can contain text, HTML elements, and other supported content.
    • < input type="submit" > : Creates a submit button whose displayed label is specified using the value attribute.
    • Both can submit a form. The < button > element offers more flexibility because it can contain formatted text and other supported content.
